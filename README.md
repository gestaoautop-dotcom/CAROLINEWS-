# Mudra Portfolio

Seção inicial (hero) de um portfólio pessoal feito com HTML, CSS, JavaScript e Bootstrap 5.

## Recursos
- Navbar fixa que muda de estilo ao rolar a página
- Efeito de digitação no título ("A Developer." / "A Designer.")
- Ícones de redes sociais e botão "Download CV"
- Indicador de scroll animado
- Layout responsivo

## Como usar
1. Clone o repositório
2. Coloque sua imagem de fundo em `img/home-bg.jpg`
3. Abra `index.html` no navegador (ou use o Live Server do VS Code)

## Tecnologias
HTML5, CSS3, JavaScript, Bootstrap 5, Font Awesome, Google Fonts (Montserrat)
